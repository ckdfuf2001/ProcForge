# 실제 모델 dogfood 2회차 — HN 일일 누적, 3 must-haves (M5.5-dogfood-real2)

날짜: 2026-10-11 ~ 12. 모델: 본 세션 (Muse Spark, 채팅+도구로 직접 수행).
세션: `fa3c1774-43ac-4b2c-857e-2e7f1fba6434` (Pf 백엔드).
실행: repo CLI + 자작 fetch MCP + python (전사 프로젝트 `dogfood-real2/proj/`, 커밋 안 함).
전사 충실도: 노드·tool·argSpecs·제약·map/until/stateWrites·스크립트 3종을
세션 호출 기록과 동일하게 재현 (sinceDays 파라미터 선언 포함).

요청문 (1문장): "Hacker News 새 글(Algolia search_by_date, tags=story) 중에서
최근 sinceDays 이내 글만 제목·날짜·본문 요약으로 CSV에 매일 누적하는 절차서를 만들어줘"

## must-have 1: 스스로 until/map/state로 나누는지 — 예
- 루트 → 3분할 (1.1 목록 until / 1.2 상세 map / 1.3 누적 state). M5.5-6 문구와
  M5.6-h 문구(둘 다 instruction에 살아 있음)가 직접 효력.
- 1.2는 평탄화 필요로 1.2.1(script) + 1.2.2(map) 재분할 — 1회차에서 이미
  알던 것이라 이번엔 선제 분할 (사전 지식 사용 고지).
- offset `+1`이 ref로 불가 → until 본문 script (instruction이 이제 명시).

## must-have 2: advise로 그 노드만 고쳐지는지 — 예 (최초 실증)
- 1.3에 llm_rubric 2건(c-sum + advise 후 hc-*)을 두고 사유 없이 보고 →
  needs_human (`fail [c-sum]`, unverified).
- advise 전 1.1·1.2.2 전문 스냅샷 → `pf_advise` (판정문 + 제약 없이 텍스트만) →
  `pf_retry` → rubricReasons 기재 보고 → pass → 확정.
- advise 후 1.1·1.2.2 재조회: args·제약·attempts·hash 전부 동일, 1.3만 변경
  (advice 1건·hc- 제약 1건·attempt 1건 추가). 부분 수정 격리 입증.
- 덤: `pf_edit_node(stateWrites 단독)`는 leaf 노드에서 `bad_request: 변경 없음` —
  하네스 경계가 stateWrites 필드를 버림 (map/until과 동일 증상, M6-d 추가 증거).

## must-have 3: 무수정 approve + 이틀 exit 0, 새 글만 — 예
- `approve hn-daily2 --node 1.2.2` (bare name, M5.6-a 수정 덕분에 동작,
  올바른 dir에 기록) → 패턴이 `$prefix` 자동 생성됨 (M5.6-b 수정 덕분,
  손댈 것 없음).
- run1 (`--param sinceDays=1`): pass=3·unverified=1(1.3 llm_rubric, exit 0 유지),
  CSV 30건, state 30 ids. map 30/30.
- run2 (약 1시간 후): pass=3·unverified=1, exit 0, CSV 1건(50047754),
  교집합 ∅, 합집합 == state(31). 중복 0 입증.

## M5.6 수정 실증 (이번 회차에서 처음 동작 확인)
- bare-name approve + 자동 `$prefix` (a·b). 1회차 때의 수기 `$prefix` 불필요.
- state save 조건이 unverified를 막지 않음 (fail·중단만 제외).

## 새로 발견 (M6 정제·추가)
- **script 재시도 없음**: until 1회차 script fetch가 egress flake(10013)로
  터지자 run 전체 실패 → 30초 후 재실행으로 통과. M5.6-f는 MCP 호출만
  커버, script leaf는 미커버. M6-f2: script 재시도 여부 결정 필요
  (멱등 스크립트 전제 하에 attempts 적용 또는 문서화).
- egress flake 재확인 (10013 간헐 2회). 스케줄러 재시도 필수 (이미 문서).
- Pf 호출 33회 + webfetch 1회 (probe는 bash python 직접 실행).
  토큰 사용량은 여전히 불가시 (하네스 과제 j 유지).
- 전사validator 성격 한계: 세션 finalize는 여전히 불가 (map/until/stateWrites
  하네스 경계 문제, M6-d 유지). repo finalize는 전사본에서 검증되지 않음
  (CLI run만 수행).

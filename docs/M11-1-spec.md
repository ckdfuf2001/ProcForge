## §1 동작 후보 (최대 2안)
- 안 a (읽기 전용 확장, 권장): 절차서별 남은 작업 수·완료율을
  `RemainingList`에 합산 표시한다. 쓰는 곳이 없어 형식이 필요 없다.
- 안 b (체크형): 완료 표시를 별도 파일(`todos.json` 제안)에 저장하고
  `procedure.json`은 건드리지 않는다.
  읽기 경로와 쓰기 경로를 분리한다.

## §2 불변 조건
- `procedure.json` 바이트 무변경 (To-Do는 별도 저장소에만 둔다).
- `approvals.json`·run 기록 불변.
- MCP 표면 불변 (신규 `pf_*` 없이 UI·로컬 API로만).

## §3 테스트 후보
- 안 a: 절차서 2개의 남은 작업 합산 표시 (미완료 수·완료율).
- 안 b: 체크 후 재조회에서 유지 + `procedure.json` 바이트 동일.
- 읽기 전용 조회는 기존 목록과 같은 순서를 낸다 (정렬 불변).

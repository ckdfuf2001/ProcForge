## 0번 사실 확인 (M5.8.1-0)

1. leaf 3개의 tool: 전부 `opencode/bash`, sideEffect none
   (근거: `procedure.json` nodes + 세션 report·confirm 호출).
2. runner 실행 불가 — 이중 차단:
   - `command`를 `path:"in"`으로 확정했더니 `rewritePaths`가 명령 문자열을
     파일 경로로 취급 → fixture 에러 (`runner/paths.ts`, 실행 시도 없음,
     `durationMs` 4~6ms).
   - 넘어가도 builtin bash는 `allowBash=true` 필요 (`runner/connections.ts:75`).
     기본값 전부 false. E2E의 어떤 실행도 이 값을 안 넘김.
   - catalog에는 `opencode/bash`가 있어 catalog 검사는 통과.
     즉 "catalog에 있음 ≠ runner가 실행함".
3. 호스트는 OpenCode, 호출은 에이전트 직접:
   - 세션 `toolCatalog`은 `opencode/*` 6종, 경고 "모르는 opencode 버전(unknown)".
   - `events.jsonl` 19건 전부 `actor:"host"`, 단일 세션 연속 호출, 하위 에이전트 없음.
   - 단 `calls.jsonl`에는 actor 기록이 없어 로그만으로 주체 구분 불가 (→ M5.8.1-6).
